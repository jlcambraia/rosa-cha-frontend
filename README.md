# Rosa Chá Creative House — Frontend

A frontend website project developed with **React 19, JavaScript, and Vite 6**.

> **Project Status:** Work in progress.

## Overview

This repository contains the frontend development of a website for Rosa Chá Creative House.

The project uses React to organize the interface into reusable components and provide a foundation for further website development.

The current application includes a main page structure with a header, home section, and footer.

## Current Implementation

- React-based application
- Reusable UI components
- Main page layout
- Header component
- Home page component
- Footer component
- Component-level styling
- Vite development environment

## Tech Stack

- React 19
- JavaScript (ES6+)
- Vite 6
- React Router DOM 7
- HTML5
- CSS3
- ESLint

## Application Structure

The main application is composed of three primary interface sections:

```text
App
 |
 +-- Header
 |
 +-- Home
 |
 +-- Footer
```

The `App.jsx` component imports and renders these sections.

React Router is included as a project dependency, providing a foundation for routing as the application evolves.

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

```bash
git clone https://github.com/jlcambraia/rosa-cha-frontend.git
cd rosa-cha-frontend
npm install
```

### Development

```bash
npm run dev
```

### Production Build

```bash
npm run build
```

### Preview

```bash
npm run preview
```

### Linting

```bash
npm run lint
```
